# 📊 Supermarket Sales | EDA + Dashboard

Análisis exploratorio de **1.400 facturas** de supermercados en **Yangon, Naypyitaw y Mandalay**, correspondientes al primer trimestre de 2019.

El objetivo: descubrir qué cuentan las ventas cuando dejamos que los datos hablen. Spoiler: febrero tenía menos transacciones, pero un ticket medio mayor. 📈

## 🔍 ¿Qué incluye?

- **EDA en Jupyter Notebook:** exploración, limpieza, comprobaciones de consistencia y conclusiones.
- **Cinco KPI:** facturación total, transacciones, COGS medio, ingreso bruto y valoración media.
- **Dashboard interactivo en Streamlit:** gráficos por ciudad y producto, evolución mensual, valoraciones y tabla resumen.
- **Filtros:** ciudad, línea de producto y rango de fechas.

## 🛠️ Tecnologías

**Python · pandas · Matplotlib · Seaborn · Jupyter · Streamlit · Git/GitHub**

```bash
pip install -r requirements.txt

```
